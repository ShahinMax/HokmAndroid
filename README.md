# حکم طلایی برای اندروید (نسخه آزمایشی 0.1)

پروژهٔ اولیهٔ Android Studio برای یک بازی حکم چهار نفرهٔ آفلاین، با رابط کاربری فارسی و تم سبز/طلایی.

## اجرای پروژه
1. Android Studio را نصب کنید.
2. از مسیر **Open** پوشهٔ `HokmAndroid` را انتخاب کنید.
3. اجازه دهید Gradle Sync تمام شود و Android SDK 35 نصب باشد.
4. دستگاه یا شبیه‌ساز اندروید را در حالت landscape اجرا کنید.
5. برای ساخت APK: از منوی **Build > Build APK(s)** استفاده کنید.

## امکانات فعلی
- چهار بازیکن، ۵۲ کارت و ۱۳ کارت برای هر بازیکن
- انتخاب خال حکم توسط کاربر
- رعایت خال اجباری، مقایسهٔ کارت‌ها و تشخیص برندهٔ هر دست
- حریف‌های سادهٔ آفلاین
- شمارش دست‌های هر تیم و امتیاز بین دست‌ها
- رابط تمام‌صفحهٔ افقی با میز سبز، قاب چوبی و رنگ‌بندی طلایی

## محدودیت‌های نسخهٔ آزمایشی
- انتخاب حکم در شروع هر دست به بازیکن داده می‌شود؛ هنوز نقش «حاکم» و روند کامل پخش ۵ کارت/انتخاب حاکم پیاده‌سازی نشده است.
- هوش مصنوعی ساده است و هم‌تیمی‌محور/استراتژیک نیست.
- دکمهٔ صدا فعلاً فقط وضعیت نمایشی را عوض می‌کند؛ صدا، چت آنلاین، حساب کاربری و چندنفرهٔ اینترنتی پیاده‌سازی نشده‌اند.
- برای انتشار در Google Play به تست روی دستگاه واقعی، آیکون، سیاست حریم خصوصی و امضای انتشار نیاز است.

این پروژه از WebView آفلاین استفاده می‌کند و برای اجرای بازی اینترنت لازم ندارد.
